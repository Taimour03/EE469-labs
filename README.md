# EE469 ROS2 Labs

Personal working repo for EE469 lab exercises.

## Layout

- `ros2_ws/`        - main colcon workspace used for the early labs
- `diffbot_arm_ws/` - colcon workspace introduced in the later hardware labs
- `submissions/`    - exact zip files (and any GenAI prompt .txt files) generated for turn-in, one subfolder per lab
- `notes/`          - one markdown note per lab: objectives, commands, issues, screenshots

## Conventions

- Package names and submission zip names follow the lab manual exactly (e.g. `le9_part1c_cpp_pkg.zip`).
- Commit after each part of a lab builds and runs cleanly, not just once at the end.
- Never commit `build/`, `install/`, or `log/` - they're regenerated by colcon.
